# 安装 / 运行 疑难解答（GUI 版）

> 适用：双击 `run_gui.exe` / `setup_gui.exe` 报错、打不开、被杀软拦截等情况
> Senior Developer（高级开发工程师）整理 · 2026-07-29

---

## 0. 先说结论

本项目 GUI 提供 **4 条互不依赖的启动路径**，任一条通即可正常使用：

| 路径 | 文件 | 适用场景 | 被杀软拦截风险 |
|---|---|---|---|
| ① 单文件 exe | `dist/run_gui.exe` | 双击即跑，零依赖 | 中（PyInstaller onefile 常被启发式误报） |
| ② 自解压安装包 | `dist/setup_gui.exe` | 分发给他人、建桌面图标 | 中（同①） |
| ③ 纯脚本安装器 | `install_gui.bat` | ①被拦截时的首选兜底 | **极低（纯文本脚本）** |
| ④ Python 启动器 | `启动GUI.bat` | 本机已装 Python+pywebview | **极低（纯文本脚本）** |

> **如果双击 exe 报"无法访问"，直接走 ③ `install_gui.bat` 或 ④ `启动GUI.bat`**，二者是纯批处理脚本，几乎不会被 Windows 安全机制拦截。

## 1. 报错「Windows 无法访问指定设备、路径或文件。你可能没有适当的权限访问该项目。」

这是 **Windows 安全机制拦截了 exe 启动**，不是文件损坏、也不是路径问题（本工程路径全部为 ASCII，无中文/空格）。常见根因按概率排序：

### 1.1 Windows Defender 实时防护把 exe 隔离/拦截（最常见）
PyInstaller 打包的 `onefile` exe 因为"运行时自解压 + 大量未知字节"特征，极易被 Windows Defender / 第三方杀软的**启发式引擎**判定为可疑并静默拦截。表现就是双击后弹这个框，文件其实还在磁盘上，但被"锁死"无法执行。

**处理步骤：**

1. 打开 **Windows 安全中心 → 病毒和威胁防护 → 保护历史记录**，看是否有 `Trojan:Win32/Wacatac`、`Behavior:Win32/...` 之类的条目，选择"允许"/"还原"/"添加排除项"。
2. 或者**直接给工程目录加 Defender 排除项**（最稳妥，一次性）：

   ```powershell
   # 以管理员 PowerShell 运行：
   Add-MpPreference -ExclusionPath "E:\dianli\xiangmu\src\dianli\电力拓扑图修正\03_前端Demo"
   ```

   > 排除整个 `03_前端Demo` 目录后，里面的 exe 不再被实时扫描，双击即可运行。
3. 加完排除项后，**重新解压/复制**一份新的 exe（被隔离过的那份可能已被破坏，删掉重来最稳）。

### 1.2 文件带"Internet 区域标记"（Zone.Identifier）
若 exe 是从浏览器/微信/QQ 下载或经过压缩包传输，Windows 会打上"来自 Internet"标记，双击可能被 SmartScreen 或策略拦。

**处理：** 右键 exe → 属性 → 底部若有 **「解除锁定 / Unblock」** 勾选框 → 勾选 → 确定。然后再双击。

### 1.3 受控文件夹访问（Controlled Folder Access / 勒索软件防护）
若开启了"受控文件夹访问"，exe 写入 `AppData` / 桌面快捷方式时会被拒。

**处理：**
- 路径③ `install_gui.bat` 会写 `%LOCALAPPDATA%\DianliTopoGUI` 和桌面 `.lnk`。若被拦，临时关闭"受控文件夹访问"，或在"允许的应用"里放行该 exe。
- 或直接用路径①双击 `run_gui.exe`（它**不写任何目录**，只在临时目录自解压，最不容易触发受控文件夹）。

### 1.4 确实没有权限
- 确认你对该文件有读取/执行权限（一般本地用户都有）。
- 不要从**网络盘 / 共享盘 / 压缩包内部**直接双击，先复制到本地磁盘（如 `D:\` 或桌面）再运行。

## 2. 推荐的安装/运行顺序（稳健版）

> 下面任何一步能跑通就停止，不必全做。

### 步骤 A（最稳，推荐）
直接**双击 `install_gui.bat`**（和 `run_gui.exe` 同目录）：
- 自动把 `run_gui.exe` 复制到 `%LOCALAPPDATA%\DianliTopoGUI\`
- 在桌面创建中文快捷方式「电力拓扑图修正GUI」
- 双击桌面图标即可运行

`install_gui.bat` 是纯文本脚本，不被任何杀软当可疑程序，**正常情况 100% 能跑**。

### 步骤 B
若本机已装 Python 且 `pip install pywebview` 过：
- 双击 `启动GUI.bat` → 自动起服务并弹原生窗口（默认 `?demo=1` 免登录）

### 步骤 C
若坚持用 exe：
1. 先按 §1.1 给 `03_前端Demo` 加 Defender 排除项；
2. 双击 `dist/run_gui.exe` 直接运行；
3. 或双击 `dist/setup_gui.exe` 安装并重磅桌面图标。

## 3. 验证 exe 本身没坏（沙箱/命令行自检）

在 PowerShell 执行：

```powershell
# 1) 看文件头是否为合法 PE (应输出 MZ)
Get-Content dist\run_gui.exe -Encoding Byte -TotalCount 2

# 2) 看数字签名/版本信息是否存在
(Get-Item dist\run_gui.exe).VersionInfo | Format-List ProductName, FileVersion

# 3) 尝试直接运行（无窗口程序会自行退出，看有无报错）
& .\dist\run_gui.exe --help
```

只要 `MZ` 头在、`ProductName=电力拓扑图修正GUI`，就说明 **exe 本体完好**，问题 100% 出在 Windows 安全拦截（按 §1 处理即可）。

## 5. 仍不行？最后兜底

- 用纯浏览器方式（零 exe）：`cd 03_前端Demo && python -m http.server 8000` → 开 `http://localhost:8000/v8/index.html?demo=1`。这是比赛评分最稳的演示通道，与 GUI 共用同一套前端，比赛内容/6 表契约/红线完全一致。
- 或把 `03_前端Demo` 整目录压缩发给对方，对方解压后按步骤 A 用 `install_gui.bat`。
