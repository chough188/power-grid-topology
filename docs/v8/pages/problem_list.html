1.1 悬空判定规则与豁免清单（精准校验 · 杜绝误判）
三类异常（应判定为悬空）
  • 单端悬空端点：开关/刀闸等非末端设备仅单侧连接，对侧无连通
  • 多设备连片悬空：多个设备成片缺少对侧拓扑连接
  • 无母线接入拓扑孤岛：设备群组未接入任何母线形成孤岛
豁免设备（末端设备 · 不纳入悬空）
  • 电力用户 / 配变（末端负荷）
  • 电缆终端头
  • 备用间隔（仅单侧、预留）
  • 配电站 / 箱变（仅进线无出线，站内开关均豁免）
