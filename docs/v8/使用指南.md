## 1. 本地运行（必须走 HTTP，不要直接双击 file://）

项目是纯静态前端（HTML+CSS+JS），**0 npm / 0 node_modules / 全离线**，仅需一个静态服务器。

```bash
# 进入"前端根目录"（使 /v8/ 与 /v8_lab/ 同时可解析）
cd E:\dianli\xiangmu\src\dianli\电力拓扑图修正\03_前端Demo

# 起一个静态服务器（Python 自带，无需安装）
python -m http.server 8000
```

浏览器打开：

```
http://localhost:8000/v8/index.html
```

> ⚠️ 不要直接 `file://` 双击打开 `index.html`：部分浏览器在 `file://` 下会限制 `localStorage` / 动态脚本，导致登录态与图表异常。务必用上面的 HTTP 方式。

### 1.1 Windows 原生桌面 GUI（答辩推荐 · 真正「GUI 界面」）

如果你要的是**像普通 Windows 软件那样的原生窗口**（而非浏览器标签页），用本项目附带的启动器即可——它用系统自带的 **Edge WebView2** 把 v8 前端包进一个原生窗口，离线、无 node、前端代码零改动。

**首次准备（每台机器一次）**
```bash
cd E:\dianli\xiangmu\src\dianli\电力拓扑图修正\03_前端Demo
pip install -r requirements-gui.txt     # 仅装一个 pywebview
```

**日常使用（零门槛）**
- 直接**双击 `启动GUI.bat`** → 自动起本地服务并弹出原生窗口（默认 `?demo=1` 免登录，附「演示模式」徽标）。
- 或命令行：`python run_gui.py`（加 `--no-demo` 走正式登录网关）。

**特性 / 稳定性设计**
- 窗口关闭即自动停掉本地服务，不留后台进程。
- 服务仅绑定 `127.0.0.1`（localhost），不暴露到外网。
- 若目标机缺失 WebView2 运行时，自动回退到系统默认浏览器打开（不会白屏崩）。
- 端口探测：首选 8731，被占用则自动换空闲端口。

## 2. 演示模式（免登录）—— 答辩首选

**方式 A：URL 参数（推荐，零改动）**
```
http://localhost:8000/v8/index.html?demo=1
# 或 http://localhost:8000/v8/pages/breakpoint.html?demo=1  （任意子页深链直达）
# 别名：?kiosk=1  效果相同
```
- 命中后写入 `sessionStorage.v8-demo=1`，**页面间跳转保持免登录**（重定向会丢 URL 参数，故用 sessionStorage 持久化）。
- 右上角登录区会出现绿色 **「演示模式」** 徽标，提示当前为免登录态。

**方式 B：永久 kiosk（改一处配置）**
打开 `v8/assets/config.js`，将
```js
DEMO_SKIP_LOGIN: false,   // ← 改为 true
```
保存后全站永久免登录，无需任何 URL 参数。

> 两种方式**默认均关闭**（不影响正式网关）。关闭时，未登录访问任意受保护页仍会被拦截跳回 `login.html`——这是预期行为，证明开关安全。

## 4. 后端切换（后端就绪后的一行操作）

数据统一经 `v8/assets/api_competition.js` 的 `compApi` 契约层取数。当前 `compApi.BACKEND.useSample = true` → 走内置样本，**无需后端即可完整演示**。

后端就绪时，只需改一处并保留安全网：

```js
// v8/assets/api_competition.js
var BACKEND = {
  useSample: false,          // ← 改为 false 即切真实接口（零成本一行切换）
  base: "/api/comp",         // 真实接口前缀，按部署环境修改
  method: "POST",            // 后端若用 GET 改 "GET"
  timeoutMs: 15000,
  fallbackToSampleOnError: true,  // 已内置：真实接口超时/HTTP/网络异常 → 优雅降级到样本，演示不白屏
};
```

> 这就是为什么当前敢一直用 `useSample=true`：即使误切或后端抖动，也有样本兜底，评委面前不会白屏。

## 8. 故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 控制台一堆 `/api/v1/*` 404 | **正常**。无后端时前端走样本（`useSample=true`），这些是被优雅降级的真实接口探测，非缺失静态资源，页面 0 pageError。 |
| 打开是白屏 | 多半是用了 `file://` 直接打开。改用 §1 的 HTTP 方式。 |
| 进任何页都被踢回 login | 演示模式未开：加 `?demo=1`，或在 config.js 设 `DEMO_SKIP_LOGIN=true`。 |
| 图表不出来 | 确认通过 HTTP 访问（非 file://）；ECharts 已从 `<head>` 移到 body 末，首屏不再被阻塞。 |
| 主题/暗色不对 | 标题栏右侧有主题切换；偏好存 `localStorage.v5-theme`。 |
| **双击 exe 报"无法访问指定设备/路径/文件"** | 几乎都是 **Windows Defender / 受控文件夹访问**拦截 PyInstaller onefile exe（exe 本体完好）。处理：① 改用 `install_gui.bat` / `启动GUI.bat` 纯脚本路径；② 或给 `03_前端Demo` 加 Defender 排除项后重跑 exe。详见 **`v8/安装疑难解答.md`**。 |
